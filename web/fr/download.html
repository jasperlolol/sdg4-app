    Obtenir l’application

    Emportez l’ODD 4 avec vous

    Installez le site comme application sur votre ordinateur ou votre téléphone. Chaque application ouvre le site complet et reste utilisable sans internet une fois ouverte.

    Windows

    Windows 10 et 11

    Téléchargez le programme d’installation et exécutez-le. Windows peut indiquer que l’éditeur est inconnu. Choisissez Informations complémentaires, puis Exécuter quand même.

    Télécharger pour Windows

    Mac

    Mac, puce Apple ou Intel

    Ouvrez le fichier téléchargé et faites glisser SDG 4 dans Applications. La première fois, macOS peut le bloquer. Ouvrez Réglages Système, allez dans Confidentialité et sécurité, puis cliquez sur Ouvrir quand même.

    Télécharger pour Mac

    Android

    Téléphones et tablettes

    Ouvrez le fichier téléchargé. Android vous demandera d’autoriser les installations depuis cette source. Activez l’option, puis installez.

    Télécharger pour Android

    iPhone et iPad

    Ajoutez-le à votre écran d’accueil

    Il n’existe pas de téléchargement pour iPhone et iPad. Ouvrez le site dans Safari, appuyez sur le bouton Partager, puis sur Sur l’écran d’accueil.

    Ouvrir le site

    Les applications sont générées automatiquement et publiées sur GitHub, où les versions précédentes sont aussi conservées. Les applications ne sont pas signées par Apple, Microsoft ou Google, donc les avertissements ci-dessus sont normaux.
