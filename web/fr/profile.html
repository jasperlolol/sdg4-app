    Votre profil et votre classe

    Choisissez votre apparence, rejoignez une classe avec un code de votre enseignant, ou activez le mode enseignant pour en créer une. Vos scores aux quiz sont envoyés à chaque classe que vous avez rejointe.

    Votre profil

    Utilisez un pseudo, pas votre nom complet. Une fois que vous rejoignez une classe, votre pseudo, votre avatar, votre couleur et votre bio sont visibles par vos camarades et votre enseignant. Ne mettez pas de renseignements personnels dans votre bio.

    Vos classes

    Créez une classe pour obtenir un code. Les élèves saisissent ce code sur cette page pour la rejoindre. Choisissez un nom que votre classe reconnaîtra.

      Code

      Les élèves pointent la caméra de leur téléphone sur ce code. La page de profil s'ouvre et ils rejoignent la classe. Ils doivent d'abord enregistrer un pseudo.

                Camarades de classe

                Tout le monde dans vos classes peut voir le pseudo, l’avatar, la couleur et la bio des autres.

                Classes et confidentialité

                Les classes ont besoin d’une connexion internet. Un enseignant peut voir le pseudo, l’avatar, la bio, les notes aux quiz et la date du dernier quiz. Les camarades peuvent voir le pseudo, l’avatar, la couleur et la bio. Rien d’autre n’est partagé.

                Effacer vos données sur cet appareil efface aussi votre compte enseignant ici : les classes créées sur cet appareil ne pourront plus être gérées.
